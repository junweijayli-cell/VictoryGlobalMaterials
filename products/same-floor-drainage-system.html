Buyer questions

Questions about Same Floor Drainage System

What is included in the listed component range?

The catalogue identifies traps, manifolds and floor drains in an HDPE same-floor drainage system. Include the bathroom layout and component quantities with your enquiry.

Can every layout avoid slab penetrations?

The original catalogue describes a no-slab-penetration approach, but the actual layout depends on the selected system and project details. Request a reviewed system drawing rather than treating that statement as a universal guarantee.
